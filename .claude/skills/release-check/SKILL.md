# Release Check

## Назначение

Финальная проверка завершённого этапа перед ручным commit/push.

## Проверить

1. `git status --short`.
2. Какие файлы изменены.
3. Нет ли неожиданных файлов.
4. `git diff --check`.
5. Syntax check изменённого JS при необходимости.
6. Нет ли debug/test/temporary кода.
7. Нет ли `console.log`, если он не нужен для обработки ошибок.
8. Не появились ли secrets/`.env`/tokens.
9. Не сломан ли scope текущей задачи.
10. Не запускать длинные проверки, если изменения маленькие и уже проверены пользователем вручную.

## Важно

Release-check НЕ делает commit и push.

## Результат

В конце:

### READY TO COMMIT

или

### NOT READY

И коротко причины.
